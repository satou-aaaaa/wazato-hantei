# わざと？わざとじゃない？

副作用のある短い話（会社・学校・町内会など）を読んで、「わざと」か「わざとじゃない」かを判定する学習ゲームです。
同じ形の話を、悪い副作用とよい副作用の2通りで答え、最後に自分の答えのかたよりを Knobe（2003）の実験（ノーブ効果・副作用効果）とくらべます。
続けて、実験の数や話の形を学ぶ問題を1日5問。

遊ぶ: <https://satou-aaaaa.github.io/wazato-hantei/>

- 判定には正解がありません。人を責めたりほめたりする練習ではなく、自分の判断のくせを知る遊びです。
- 話はこのゲームで作ったもので、実在の人や会社ではありません。話の形は Knobe（2003）の1つ目の実験と同じです。
- 数は原典の値だけを使います。
  - Joshua Knobe (2003) "Intentional Action and Side Effects in Ordinary Language", Analysis 63(3): 190–194. <https://doi.org/10.1111/1467-8284.00419>
    （1つ目の実験：78人、悪い副作用82%・よい副作用23%が「わざと」。2つ目の実験：42人、77%・30%。責める強さ4.8・ほめる強さ1.4）
  - Florian Cova ほか (2021) "Estimating the Reproducibility of Experimental Philosophy", Review of Philosophy and Psychology 12: 9–44. <https://doi.org/10.1007/s13164-018-0400-9>
    （40本をやり直し、およそ7割で同じ結果。Knobe 2003 も同じ向きに出た）
